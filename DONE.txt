🎓 SIMPLE EXPLANATION:

Your Website:

├─ HTML (all pages)

├─ Receives touch input from Raspberry Pi
├─ Recognizes swipe gesture
├─ Reads your CSS rules
└─ Applies smooth scrolling ✨

Raspberry Pi:
├─ Detects physical touch on screen
├─ Sends touch input to browser
└─ Browser does the rest!
